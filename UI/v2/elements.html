Glossario componenti · UI v2

Toolkit della dashboard illustrata. I componenti usano il prefisso vv2- e sono definiti in css/vv-ui-v2/. Entry point: css/style-v2.css. Font: Fraunces (titoli) e Lexend (dati). Sul sito e in anteprima i font arrivano da Google; sulla scheda ESP32 si usano i fallback di sistema.

Principi

Carta calda, inchiostro scuro, un solo accento verde. I titoli sono in serif; i numeri e le etichette in sans. L’illustrazione non è decorativa: reagisce alle letture. Le card generiche sono evitate: si raggruppa con linee e spazi.

Classi utility

Per piccoli aggiustamenti di spazio, colore o allineamento si usano classi pronte, basate sulla scala dei token. La scala degli spazi ha passo 4 px: 0 = 0, 1 = 4, 2 = 8, 3 = 12, 4 = 16, 5 = 24, 6 = 32, 7 = 48, 8 = 64. Usarle evita stili inline e tiene le distanze coerenti.

Stati della pagina

.vv2-dash--loading — numeri in shimmer in attesa della prima lettura.

.vv2-dash--stale — illustrazione in grigio e letture attenuate se la scheda non risponde.

Le animazioni continue (nebbia, oscillazione, LED) si disattivano con prefers-reduced-motion.

Come usarli

Pagina minima

<link rel="stylesheet" href="css/style-v2.css" /> <body class="vv2-page" data-source="demo"> … markup come in UI/v2/index.html … <script src="js/vv-data.js"></script> <script src="js/v2/vv2-jar.js"></script> </body> data-source="demo" → valori simulati data-source="/api/readings" → ESP32

Aggiungere una lettura

1. Aggiungi un blocco .vv2-reading con id, data-min/max/low/high (e data-scale="log" se serve).

2. In js/v2/vv2-jar.js, estendi valuesOf, DECIMALS e, se vuoi un consiglio, ADVICE e PRIORITY.

Copia per l’ESP32

cd examples/wifi-illustrated ./build-data.sh # poi carica data/ in LittleFS (vedi README dell’esempio)
